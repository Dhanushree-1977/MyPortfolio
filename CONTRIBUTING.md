# Contributing to Portfolio

Thank you for your interest in contributing to my portfolio website!

## How to Contribute

1. **Fork the Repository**:
   Click the **Fork** button on the top right of the repository page.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/<your-username>/CodeSoftInternship.git
   cd CodeSoftInternship
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```

4. **Make Your Changes**:
   - Keep styling consistent with the existing cyberpunk dark neon theme.
   - Test changes locally across desktop, tablet, and mobile breakpoints.
   - Verify that links and assets remain intact.

5. **Commit and Push**:
   ```bash
   git commit -m "Add: descriptive message about feature"
   git push origin feature/amazing-feature
   ```

6. **Submit a Pull Request**:
   Open a pull request describing the changes and improvements made.

## Suggestions and Bug Reports

If you discover any bugs or have suggestions for design improvements, feel free to [open an issue](https://github.com/Dhanushree-1977/CodeSoftInternship/issues).
