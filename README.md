## 🔭 Overview

Welcome to my portfolio repository! This website serves as the primary gateway to my professional journey as an aspiring **Software Developer**. It is designed with a dark cyberpunk-inspired theme featuring glowing accents, smooth animations, interactive skill metrics, and detailed showcases of my featured projects.

Built with clean, semantic HTML5, modern CSS3 (Custom Variables, Flexbox, Grid), and vanilla JavaScript for peak performance and zero dependencies.

---

## ✨ Key Features

- **🌌 Futuristic Dark Neon Aesthetics:** Deep navy/space background with animated star layers, glowing borders, and vibrant gradient accents (`#f21d8b` pink to `#00e1ff` cyan).
- **📱 Fully Responsive Design:** Optimized across all screen sizes (desktop, laptops, tablets, and smartphones) with a dynamic mobile navigation menu.
- **⚡ Smooth Scroll & Reveal Animations:** Built using modern `IntersectionObserver` API for smooth scroll reveals without bloated third-party libraries.
- **📊 Interactive Skill Bars:** Dynamic visual indicators for programming languages and frameworks (Python, Java, HTML/CSS, JavaScript, SQL, Django, Git, Docker).
- **🚀 Project Showcase Cards:** Clean cards detailing project background, key technologies, and direct links to repository code.
- **📄 Instant Resume Access:** One-click download button for my updated curriculum vitae.
- **🌐 SEO & Social Media Ready:** Complete Open Graph and Twitter Card metadata for rich previews when shared on LinkedIn, Discord, and messaging apps.

## 💻 Getting Started Locally

You can run this project locally in two ways:

### Option A: Using the Python Flask Server (Recommended)
```bash
pip install -r requirements.txt
python app.py
```
Then open your browser to **http://127.0.0.1:5000**.

### Option B: Standalone Static Browser
Double-click `index.html` to open it in your browser, or serve with VS Code **Live Server** extension.

## 🌐 GitHub Pages Deployment

This repository is configured with a GitHub Actions workflow (`.github/workflows/deploy.yml`) for automated deployment.

To enable GitHub Pages on your repository:
1. Go to your repository on GitHub: `https://github.com/Dhanushree-1977/MyPortfolio`.
2. Click **Settings** → **Pages** (under the "Code and automation" sidebar).
3. Under **Build and deployment** → **Source**, select **GitHub Actions**.
4. Every push to the `main` branch will automatically build and publish your site!
5. Your live site will be accessible at:
   ```
   https://dhanushree-1977.github.io/MyPortfolio/
   ```
